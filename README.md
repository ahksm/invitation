# Invitations

Платформа приглашений по шаблонам: кабинет пользователя, Telegram-бот и мини-апп, оплата через Multicard, SMS через Eskiz и админка владельца.

## Что умеет

- **Вход** по номеру телефона с кодом из SMS или через Telegram (кнопка на сайте, бот, мини-апп). Номер телефона обязателен: при входе через Telegram бот просит поделиться контактом.
- **Приглашения**: общее (одна ссылка для всех) или персональное (своя ссылка каждому гостю), ответы гостей «приду / не смогу».
- **SMS гостям** со ссылкой на персональное приглашение, если для шаблона включены SMS.
- **Языки**: интерфейс и каждое приглашение на русском, узбекском или английском.
- **Тарифы**:
  - бесплатный доступ, выданный владельцем: всё бесплатно;
  - общий шаблон: оплата за шаблон;
  - персональные приглашения: оплата за каждого гостя;
  - подписка: любые шаблоны без оплаты, места гостей оплачиваются отдельно.
- **Админка** (`/admin/`): кто пользовался платформой, приглашения и платежи каждого, журнал действий и SMS, выдача бесплатного доступа и блокировка, цены, шаблоны.

## Стек

Node.js 22, TypeScript, Fastify, PostgreSQL (Drizzle ORM), Redis (кэш, лимиты, коды входа), grammY (бот).

## Запуск

```bash
cp .env.example .env   # заполнить
docker compose up --build
```

Локально без Docker нужны PostgreSQL и Redis:

```bash
npm install
npm run db:migrate
npm run dev            # http://localhost:3000
npm test               # нужна база invite_test, см. test/api.test.ts
```

Миграции и базовый шаблон применяются и при старте сервера. После изменения `src/db/schema.ts` выполните `npm run db:generate`.

Для разработки удобно `PAYMENT_PROVIDER=mock` и `SMS_PROVIDER=mock`: оплата проходит на тестовой странице, а SMS (в том числе коды входа) пишутся в лог. В production эти режимы запрещены.

## Безопасность

- Ключи только в `.env` или секретах хостинга, в репозиторий они не попадают.
- Сессия в httpOnly-cookie, изменяющие запросы принимаются только со своего домена.
- Лимиты запросов в Redis: общий, на вход, на коды SMS (раз в минуту и 5 в час на номер), на рассылку SMS.
- Код из SMS хранится в виде HMAC, сгорает после 5 неверных попыток.
- Вход через Telegram: сессию получает только браузер, начавший вход; вход подтверждается кнопкой в боте.
- Подписи проверяются у мини-аппа Telegram, вебхука бота (secret token) и колбэков Multicard; колбэк Eskiz защищён секретом в адресе.
- Повторный колбэк об оплате ничего не начисляет дважды, сумма сверяется с заказом.

## Перед запуском в бой

1. **Multicard**: получить ИКПУ и код упаковки услуги на tasnif.soliq.uz и указать их в `MULTICARD_MXIK` и `MULTICARD_PACKAGE_CODE` (без них счёт не создаётся), при необходимости `MULTICARD_VAT`. Боевой адрес `https://mesh.multicard.uz`. Колбэк приходит на `https://<домен>/api/payments/multicard/callback`; ответ не 200 отменяет оплату, поэтому отказ даётся только при неверной подписи, неизвестном заказе или несовпадении суммы.
2. **Eskiz**: отправить на модерацию тексты SMS из `src/sms/texts.ts` (6 шаблонов: код входа и приглашение на трёх языках), задать `SMS_CALLBACK_SECRET`. Тестовый аккаунт Eskiz отправляет только фразу «This is test from Eskiz»: для разработки есть `ESKIZ_TEST_MODE=true`, тогда настоящий текст с кодом пишется в лог.
3. **Telegram**: создать бота в @BotFather, указать `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `TELEGRAM_MODE=webhook` и `TELEGRAM_WEBHOOK_SECRET`. Кнопка мини-аппа ставится автоматически, если `APP_URL` начинается с https.
4. Указать себя в `ADMIN_PHONES` или `ADMIN_TELEGRAM_IDS`.

## Устройство

```
src/
  app.ts            Fastify: защита, сессии, маршруты
  server.ts         запуск API и бота
  pricing.ts        правила оплаты
  i18n.ts           языки, переводы ошибок и текстов бота
  auth/             вход через Telegram и одноразовые ссылки
  bot/              Telegram-бот
  payments/         Multicard и тестовый провайдер
  sms/              Eskiz, тестовый провайдер, тексты SMS
  services/         пользователи, приглашения, заказы, телефоны, SMS
  routes/           HTTP API
public/
  app/              кабинет пользователя и мини-апп
  admin/            админка
  invite/           страница приглашения для гостей
```

Страница приглашения в `public/invite/` временная: её заменит обложка по дизайну InviteCover.
